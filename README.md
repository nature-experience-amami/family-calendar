# family-calendar

家族4人の予定共有アプリ（送迎の担当決め付き）

公開URL：https://nature-experience-amami.github.io/family-calendar/

## いまの段階

- スマホ向けのWebアプリ。HTML / CSS / JavaScript だけで、ビルドは不要です。
- Firebase は公式CDN（ES モジュール）から読み込みます。npm は使いません。
- 予定と送迎の担当は Firestore に保存し、家族の誰かが変えるとほかのスマホにもすぐ反映されます。
- ログインは匿名ログイン。初回だけ招待コードを入れて、自分（父・母・長男・長女）を選びます。
- ホーム画面に追加すると、アプリのアイコン（家族カレンダー）で開けます。

## できること

- 画面上部で「今日｜週｜月｜家族」を切り替え
  - 今日：時間順の予定一覧（誰の予定かを色ラベルで表示）。下に「これからの予定」（明日以降を日付順に10件ずつ、「もっと見る」で続き）
  - 週：縦が曜日、横が家族4人の一覧表。「前の週」「次の週」で7日ずつ移動、「今日に戻る」
  - 月：日付のマスに予定がある人の色の点、送迎が未定の日は「!」。日付を押すとその日の予定を下に表示。「前の月」「次の月」「今月に戻る」
  - 家族：4人のカードに「いま」と「つぎ」の予定（「つぎ」は60日先まで）
- 予定の追加：「誰の・何・いつ」だけで保存
  - 「終日」をオンにすると時間なし。オフなら開始時間（必須）と終了時間（任意）。1日だけの予定で終了が開始より前なら保存できない
  - 「終わりの日」（任意）で何日か続く予定（旅行・合宿など）。期間中の毎日に表示。終わりの日は始まりの日から62日先まで
  - 「送迎が必要」をオンにすると行き（送り）/帰り（お迎え）と時間を入力。送りの初期値は開始時間、お迎えの初期値は終了時間
  - 「くり返し」：なし／毎日／毎週（曜日を複数）／毎月（同じ日付）。くり返しの終わりの日は任意（空欄なら続ける）。くり返しの予定は1日ずつ
- 予定の編集・削除：今日・月の一覧の「編集」、これからの予定の行を押す。くり返しの予定は「この日だけ」か「これ以降すべて」を選ぶ
- くり返しの予定には小さな印（矢印の輪）。送迎の担当は日ごとに決める
- 一覧の時間は「終日」「9:00〜」「9:00〜15:00」のように入っている分だけ表示。終日の予定は時間付きより上
- 送迎が未定の予定は黄色で「誰が行く？」。押すと「父が行く／母が行く」で確定（確定後はグレー、取り消しも可）
- 祝日：振替休日・国民の休日も含めてアプリの中で計算（`holidays.js`、2020〜2099年）。月の表示は赤い日付と名前、週・今日の見出しにも名前
- 休みの日：
  - いつもの決まり（休みの曜日・祝日は休みか）は「名前・アイコン・休み」で人ごとに設定
    - 最初の決まり：父＝土日休み・祝日は仕事／母＝火水休み・祝日は仕事／長男・長女＝土日休み・祝日は休み
  - 決まりと違う日（父の祝日休み、母の振替休み・出勤、子どもの土曜登校と月曜の休みなど）は、月の表示で日付を押して「お休み」で切り替え。いつもどおりに戻すと変更は消える
  - 表示：今日の見出しの下に「お休み」、週は休みの人の欄に「休」、家族のカードに「今日はお休み」
- 右上の「自分」ボタンのメニュー
  - 名前・アイコン・休み：4人それぞれの名前（1〜10文字）とアイコン（8種類）、休みの決まりを変えられる。家族全員の画面にすぐ反映
  - 自分を変える（招待コードがもう一度必要）

家族の色：父＝青、母＝橙、長男＝緑、長女＝紫

予定や送迎の担当は固定ID（`father` / `mother` / `son` / `daughter`）でひもづけているので、名前を変えても予定はずれません。以前の版で保存された `papa` / `mama` の予定も読めて、送迎の担当を決めたときに新しいIDへ直ります。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み（タブ・参加画面・追加画面・送迎の担当決め） |
| `style.css` | 見た目（色・ボタン44px以上・Noto Sans JP） |
| `app.js` | Firebase への接続、画面の切り替え・追加・送迎・名前とアイコンの処理 |
| `icons.js` | 家族のアイコン8種類（線画のSVG） |
| `holidays.js` | 日本の祝日の計算（振替休日・国民の休日を含む） |
| `manifest.json` | ホーム画面に追加したときのアプリ名とアイコン |
| `icons/` | アプリのアイコン（`icon.svg`、iPhone用 `apple-touch-icon.png` 180px、`icon-192.png`、`icon-512.png`） |
| `firebase-config.js` | Firebase の接続先（公開してよい値）と家族グループ名 |
| `firestore.rules` | Firestore のセキュリティルール（Firebase の画面に貼る） |

## Firestore のデータ

```
families/home/private/invite      招待コード { code }（アプリからは読めない）
families/home/members/{端末のID}   参加した端末 { member, inviteCode, joinedAt }
families/home/events/{予定のID}    予定 { member, title, date, endDate, allDay, start, end, ride, repeat, repeatUntil, createdBy, createdAt, updatedAt }
families/home/profiles/{father など} 名前とアイコン・休みの決まり { name, icon, offDays, holidayOff, updatedBy, updatedAt }
families/home/overrides/{元の予定のID_日付} くり返しの予定の、その日だけの変更・送迎の担当・削除
families/home/dayoffs/{日付_人}    その日だけの休みの変更 { member, date, off, updatedBy, updatedAt }
```

## 読み込み

Firestore からは、表示している期間の予定だけを読みます（今日の画面は今日の分と「これからの予定」の件数分、週は7日分、月は1か月分、家族は今日から60日分）。
何日か続く予定は「終わりの日」でも探すので、前の月から続く旅行なども表示されます。この探し方のため、終わりの日は62日先までにしています。
くり返しの予定は、表示している期間より後まで続くもの（`repeatUntil`）を読んで、画面で日ごとに広げます。その日だけの変更は表示している期間の分だけ読みます。「これからの予定」には、くり返しの予定を92日先まで出します。

## 守っていること

- `firebaseConfig` の値はブラウザに公開される前提のもので、パスワードではありません。データは `firestore.rules` で守っています。
- 招待コードは Firestore の中だけに置き、コードには書きません。
- 招待コードが合っている端末だけが家族グループに入れて、入った端末だけが予定を読み書きできます。
- 予定の削除は、家族グループに参加している端末だけができます。

## 端末を外したいとき

Firebase の画面 → Firestore → `families/home/members` から、その端末のドキュメントを削除します。
招待コードを変えたいときは `families/home/private/invite` の `code` を書き換えます（参加済みの端末はそのまま使えます）。

# family-calendar

家族4人の予定共有アプリ（送迎の担当決め付き）

## いまの段階

- スマホ向けのWebアプリ。HTML / CSS / JavaScript だけで、ビルドは不要です。
- データは保存しません（仮データで動きます。追加した予定は再読み込みで消えます）。

## できること

- 画面上部で「今日｜週｜家族」を切り替え
  - 今日：時間順の予定一覧（誰の予定かを色ラベルで表示）
  - 週：縦が曜日、横が家族4人の一覧表
  - 家族：4人のカードに「いま」と「つぎ」の予定
- 予定の追加：「誰の・何・いつ」だけで保存。「送迎が必要」をオンにすると行き/帰りと時間を入力
- 送迎が未定の予定は黄色で「誰が行く？」。押すと「パパが行く／ママが行く」で確定（確定後はグレー、取り消しも可）

家族の色：パパ＝青、ママ＝橙、長男＝緑、長女＝紫

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み（タブ・追加画面・送迎の担当決め） |
| `style.css` | 見た目（色・ボタン44px以上・Noto Sans JP） |
| `app.js` | 仮データと画面の切り替え・追加・送迎の処理 |

## 手元で見る

`index.html` をブラウザで開くだけで動きます。
